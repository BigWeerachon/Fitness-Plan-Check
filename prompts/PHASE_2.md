# Prompt เฟส 2: สร้างจนเสร็จ

> วิธีใช้: ใช้หลังตรวจผลงานเฟส 1 และตอบ `docs/OPEN_QUESTIONS.md` แล้ว คัดลอกข้อความในกล่องด้านล่างไปวางในเครื่องมือ AI ที่เปิด repo นี้
> ถ้าเซสชันขาดกลางทาง ให้สั่งต่อว่า "อ่าน docs/PROGRESS.md แล้วทำเฟส 2 ต่อจากจุดที่ค้าง"

```
คุณคือ Senior Mobile Developer ทำงาน "เฟส 2: สร้างแอปจนเสร็จสมบูรณ์" ในโปรเจกต์นี้
อ่านเอกสารทั้งหมดใน docs/ ก่อน โดยเฉพาะ SPEC.md, ARCHITECTURE.md, DESIGN_SYSTEM.md, TASKS.md, HUMAN_TASKS.md, TEST_PLAN.md, OPEN_QUESTIONS.md และภาพ docs/reference/theme-reference.jpg แล้วทำตาม TASKS.md ตามลำดับจนครบทุกงาน

กฎเหล็ก:
1. ห้ามหยุดกลางทาง และห้ามถามฉันเพื่อขออนุญาตทำต่อ ให้ทำต่อเนื่องจนทุกงานใน TASKS.md เสร็จ
2. ถ้าเจอจุดกำกวม ให้ตัดสินใจตามค่าเริ่มต้นใน SPEC แล้วบันทึกเหตุผลสั้นๆ ใน docs/DECISIONS.md แล้วไปต่อ
3. ถ้าติดเรื่องที่ต้องใช้บัญชี/คีย์จริงที่ฉันยังไม่ได้ให้ (Supabase, RevenueCat, Google/Apple OAuth, สโตร์) ให้เขียนโค้ดผ่าน interface โดยอ่านค่าจาก .env และใช้ mock adapter สำหรับ dev/test ให้ทุกอย่างรันและเทสต์ได้โดยไม่ต้องมีคีย์จริง แล้วเขียนสิ่งที่ฉันต้องทำเพิ่มลง docs/HUMAN_TASKS.md จากนั้นทำงานถัดไปทันที
4. หลังจบแต่ละงาน: รัน typecheck + lint + เทสต์ทั้งหมด แก้จนผ่าน แล้วอัปเดต docs/PROGRESS.md (เสร็จ / กำลังทำ / เหลือ) และ commit ด้วยข้อความที่ชัดเจน เพื่อให้เริ่มต่อจากจุดเดิมได้ถ้าเซสชันขาด
5. ห้ามลดสเปคเพื่อให้งานง่ายขึ้น ห้ามข้ามเทสต์ ห้ามลบฟีเจอร์ ห้ามเพิ่มฟีเจอร์นอกสเปค ห้ามเหลือ TODO ในโค้ดที่ไม่ได้บันทึกไว้ใน PROGRESS.md
6. สิ่งที่ต้องไม่พลาดเป็นพิเศษ:
   (ก) ห้ามเริ่มซื้อ/เริ่มทดลองก่อนล็อกอิน (SPEC B4)
   (ข) ล็อกทุกฟีเจอร์เมื่อไม่มีสิทธิ์ ยกเว้นรายการใน B3
   (ค) ทดลองฟรีใช้ระบบสโตร์เท่านั้น ห้ามมีตัวนับเวลาทดลองเองในแอป (B2)
   (ง) ไม่โฆษณาทดลองฟรีกับผู้ที่ไม่มีสิทธิ์ (B6) และข้อความ Paywall ครบตาม B5
   (จ) ข้อมูลผู้ใช้ไม่หายเมื่อล็อกอิน/ซิงก์/สิทธิ์หมด
   (ฉ) ราคาแสดงจากสโตร์ ไม่ฮาร์ดโค้ด
   (ช) สถิติ % ผลรวม 100% และคิดจาก snapshot
   (ซ) ทุกสูตรและ state machine มี unit test
   (ฌ) UI ไทย/อังกฤษครบ ไม่มีข้อความฮาร์ดโค้ด
   (ญ) UI ทุกหน้าตรงภาษาภาพตามหมวด [DS] และ DESIGN_SYSTEM.md (พื้นดำ + แสงเรืองสีหลัก, หัวข้อใหญ่สีหลัก, การ์ดเทาเข้มมุมโค้งในกรอบเดียว, แถวจุดวัน, แถบแคปซูลลอย) ทั้งโหมดมืดและสว่าง และ contrast ผ่านทุกสีหลัก
7. เขียนโค้ดอ่านง่าย มี comment ภาษาไทยเฉพาะส่วนซับซ้อน รายงานความไม่แน่ใจตรงๆ ใน DECISIONS.md แทนการเดาเงียบๆ

เมื่อทำครบทุกงาน:
- รันตรวจสอบสุดท้ายเต็ม: typecheck, lint, เทสต์ทั้งหมด, build development สำหรับ iOS และ Android (เท่าที่สภาพแวดล้อมรันได้)
- ทำตารางตรวจย้อนกลับ docs/FINAL_CHECK.md ว่าทุกข้อของ SPEC ผ่านหรือไม่ พร้อมหลักฐาน (ไฟล์/เทสต์ที่รองรับ) ข้อที่ไม่ผ่านให้แก้แล้วตรวจซ้ำจนผ่าน
- ทำเช็กลิสต์ส่งรีวิวสโตร์ (SPEC N1–N6) เตรียม metadata และข้อความ App Review Notes
- สรุปสุดท้ายสั้นๆ: สิ่งที่เสร็จ, สิ่งที่ฉันต้องทำเองตามลำดับใน HUMAN_TASKS.md (ใส่คีย์, สร้างสินค้า/free trial offer ในสโตร์, ตั้งราคา, สร้าง build ส่งสโตร์), และความเสี่ยงที่ยังเหลือ
ห้ามหยุดก่อนถึงขั้นสรุปสุดท้าย ยกเว้นเหลือแต่สิ่งที่เป็นไปไม่ได้จริงๆ ที่ต้องใช้มนุษย์ ซึ่งต้องระบุไว้ครบใน HUMAN_TASKS.md
```
