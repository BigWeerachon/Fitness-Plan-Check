# ไอคอนแอป — brief และไฟล์ปัจจุบัน (SPEC N6, DS)

## 1. ไฟล์ที่มีอยู่แล้วใน `assets/` (ตรวจขนาดจริงแล้ว)

ทุกไฟล์สร้างด้วย `scripts/generate-icons.py` (Pillow) ตามภาษาภาพ DS: พื้นดำ + แสงเรืองม่วง + ดัมเบลเส้นมนและเครื่องหมายถูกสีชมพูม่วง `#E5A9DC`

| ไฟล์ | ขนาด / ชนิด | ใช้ที่ไหน (`app.config.ts`) | หน้าตา |
|---|---|---|---|
| `assets/icon.png` | 1024 × 1024, RGB (**ไม่มี** alpha — ตรงข้อกำหนด App Store) | `icon` (iOS และค่าเริ่มต้นของทุกแพลตฟอร์ม) | พื้นดำ แสงเรืองม่วง `#6E3B8F` แบบ radial จากขอบบน ดัมเบล + เครื่องหมายถูกตรงกลาง |
| `assets/android-icon-foreground.png` | 1024 × 1024, RGBA พื้นโปร่งใส | `android.adaptiveIcon.foregroundImage` | ดัมเบล + เครื่องหมายถูก ย่อ 75% กินพื้นที่ราว 44% × 33% ของภาพตรงกลาง (อยู่ในวงปลอดภัยของ adaptive icon) |
| — | สีพื้น `#000000` | `android.adaptiveIcon.backgroundColor` | พื้นดำล้วน (ไอคอน Android **ไม่มี** แสงเรืองแบบ iOS) |
| `assets/android-icon-monochrome.png` | 1024 × 1024, RGBA ลายเส้นสีขาว | `android.adaptiveIcon.monochromeImage` | สำหรับ themed icon ของ Android 13+ |
| `assets/splash-icon.png` | 1024 × 1024, RGBA | ปลั๊กอิน `expo-splash-screen` (`imageWidth: 160`, พื้น `#000000`) | สัญลักษณ์เดียวกันขนาดใหญ่ |
| `assets/favicon.png` | 48 × 48 | เว็บพรีวิวเท่านั้น (ไม่ได้ส่งสโตร์) | — |

**ยังไม่มี:** ไอคอนหน้าร้าน Google Play 512 × 512 และ feature graphic 1024 × 500 (ทำตามข้อ 4 และ [screenshots.md](screenshots.md) ข้อ 5)

## 2. Brief สำหรับนักออกแบบ (ถ้าจะออกแบบใหม่หรือขัดเกลา)

- **แนวคิด:** "วางแผนแล้วติ๊ก" — ดัมเบล (การฝึกด้วยน้ำหนัก) + เครื่องหมายถูก (ติ๊กเซ็ต/รู้ว่าวันนี้ทำอะไร) ตรงกับหน้าเซสชันที่ติ๊กวงกลมทีละเซ็ต (SPEC G1) และหลักการ "เปิดแล้วรู้ทันทีว่าวันนี้ต้องทำอะไร" (SPEC A)
- **สี:** สัญลักษณ์สีหลักค่าเริ่มต้น **`#E5A9DC`** (ชมพูม่วงอ่อน) บนพื้น **`#000000`** แสงเรืองม่วงนุ่มๆ จากด้านบน (โทนเดียวกับ `GlowBackground` ในแอป) — ไม่ใช้สีอื่นเพิ่ม ไม่ไล่สีหลายชั้น
- **สัญลักษณ์:** ลายเส้นหนาเท่ากัน ปลายมน (เหมือนไอคอนเส้นบางในแถบเมนู แต่หนาพอให้อ่านออกที่ขนาดเล็ก) อยู่กลางภาพ เรียบง่ายพอจำได้ที่ขนาด 40 px
- **ห้าม:** ตัวหนังสือหรือชื่อแอปในไอคอน, คำว่า "Pro"/"Free"/ราคา, รูปถ่าย, ภาพคน, โลโก้ Apple/Google, ภาพหรือไอคอนที่ไม่มีลิขสิทธิ์ (SPEC F9), ใส่มุมโค้งหรือเงาเอง (ระบบใส่ให้)
- **ทดสอบ:** ดูที่ 1024, 180, 120, 80, 40 px บนวอลเปเปอร์สว่างและมืด, ดูในหน้ากากวงกลม/สี่เหลี่ยมมนของ Android, ดูแบบ themed (monochrome)

## 3. ขนาดที่ต้องมี

| ที่ใช้ | ขนาด | ข้อกำหนดสำคัญ | ไฟล์ |
|---|---|---|---|
| App Store (ไอคอนแอปและหน้าร้าน) | 1024 × 1024 PNG | ไม่มีพื้นโปร่งใส ไม่ใส่มุมโค้งเอง (iOS ใส่หน้ากากให้) — Expo สร้างขนาดเล็กทั้งหมดจากไฟล์นี้ตอน build และ App Store Connect ใช้ไอคอนจาก build | `assets/icon.png` ✓ |
| iOS ไอคอนแบบมืด/tinted (ไม่บังคับ) | 1024 × 1024 | `app.config.ts` รองรับ `ios.icon` เป็นออบเจ็กต์ `{ light, dark, tinted }` หรือโฟลเดอร์ `.icon` (ตาม type ของ Expo SDK 57 ใน `node_modules/@expo/config-types`) — ถ้าต้องการต้องให้ผู้พัฒนาเพิ่มไฟล์และแก้ config | ยังไม่มี |
| Android adaptive icon | ผืน 108 dp (ไฟล์ 1024 × 1024) | ส่วนสำคัญต้องอยู่ในวงกลมกลางภาพเส้นผ่านศูนย์กลาง 66 dp (ราว 61% ของความกว้าง) เพราะแต่ละยี่ห้อตัดหน้ากากไม่เหมือนกัน | foreground ✓ / พื้นสีดำ ✓ / monochrome ✓ |
| Android แบบมีแสงเรือง (ไม่บังคับ) | 1024 × 1024 | ถ้าอยากให้ Android มีแสงเรืองเหมือน iOS ต้องทำภาพพื้นหลังแล้วให้ผู้พัฒนาตั้ง `android.adaptiveIcon.backgroundImage` | ยังไม่มี |
| Google Play หน้าร้าน | 512 × 512 PNG 32-bit, ไม่เกิน 1024 KB | เป็นภาพสี่เหลี่ยมเต็ม ไม่ใส่มุมโค้ง/เงาเอง (Play ใส่ให้) | สร้างตามข้อ 4 |
| Google Play feature graphic | 1024 × 500 JPEG หรือ PNG 24-bit | ดู [screenshots.md](screenshots.md) ข้อ 5 | ยังไม่มี |

> ข้อกำหนดของสโตร์อาจเปลี่ยน — ตรวจหน้าอัปโหลดของ App Store Connect / Play Console อีกครั้งตอนทำจริง

## 4. คำสั่งที่ใช้

```bash
# สร้างไอคอนชุดในแอปใหม่ทั้งหมด (ต้องมี Python 3 + Pillow) แล้วรัน npm run check
pip install Pillow
python3 scripts/generate-icons.py assets

# ไอคอนหน้าร้าน Google Play 512×512 จาก assets/icon.png (อย่า commit ไฟล์ผลลัพธ์เข้า repo)
python3 -c "from PIL import Image; Image.open('assets/icon.png').resize((512, 512), Image.LANCZOS).save('play-icon-512.png')"
```

ถ้าใช้ไอคอนที่ออกแบบเอง: ทับไฟล์ชื่อเดิมด้วยขนาดเดิม (foreground ของ Android วางสัญลักษณ์ในวงปลอดภัยตามข้อ 3) แล้วรัน `npm run check` (HUMAN_TASKS ข้อ 3)
