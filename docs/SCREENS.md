# หน้าจอและการนำทาง (SCREENS)

> Expo Router (`src/app`) — ทุกหน้าใช้คอมโพเนนต์ธีมจาก `src/components` ภาพจริงของแต่ละหน้าอยู่ที่ `docs/screenshots/` (สร้างด้วย `npm run preview:web` + `scripts/web-screenshots.js`)

## 1. แผนผังการนำทาง

```
เปิดแอป ─▶ _layout (โหลดฟอนต์ · เปิด DB + migration · โหลดตั้งค่า · ตรวจสิทธิ์จากแคช/RevenueCat)
   │
   ├─ ยังไม่ผ่านตั้งค่าเริ่มต้น ─▶ /onboarding (ขั้น 1 ภาษา/ธีม/สีหลัก) ─▶ /onboarding/profile (ขั้น 2, ข้ามได้)
   │                                 ─▶ /onboarding/program (ขั้น 3 เลือกเทมเพลต/สร้างเอง/ข้าม) ─▶ /paywall
   │
   ├─ /paywall ── เลือกแพ็กเกจ ─▶ (ยังไม่ล็อกอิน) /login ─▶ กลับ /paywall พร้อมแพ็กเกจเดิม ─▶ หน้าซื้อของสโตร์ ─▶ /(app)
   │      └─ ⚙ /account · Restore · Privacy · Terms · แหล่งอ้างอิง (เข้าถึงได้เสมอ B3)
   │
   └─ /(app)  ◀── AccessGate: ต้องมีสิทธิ์ (ทดลอง/รายเดือน/ซื้อขาด/ผ่อนผัน) ไม่งั้นไป /paywall
         (tabs) แถบแคปซูลลอย 4 แท็บ: วันนี้ /  ·  โปรแกรม /programs  ·  สถิติ /stats  ·  ตั้งค่า /settings
         ├─ /week                     ตารางประจำสัปดาห์
         ├─ /program/[id], /program/templates
         ├─ /routine/[id]
         ├─ /exercises (เลือก/ค้นหา), /exercises/new, /exercises/[id]
         ├─ /session/[id] ─▶ /session/summary/[id]
         ├─ /history, /history/[id]
         ├─ /stats/exercise/[id]
         └─ /profile                  โปรไฟล์และเป้าหมาย
```

## 2. รายการหน้า

สถานะทั่วไปที่ทุกหน้ามี: **loading** = ตัวหมุนกลางจอ (ใช้น้อยมากเพราะ SQLite ในเครื่องอ่านแบบ synchronous), **ว่าง** = `EmptyState` ไอคอน + ข้อความ + ปุ่มทำต่อ, **error** = `ErrorState` ภาษาง่าย + ยืนยันว่าข้อมูลในเครื่องปลอดภัย, **ถูกล็อก** = ทุกหน้าใน `(app)` ถูกพาไป Paywall โดยไม่ลบข้อมูล

## 3. องค์ประกอบร่วม

- **Sheet** (แผ่นล่าง): เมนู ⋯, ตัวเลือก, ฟอร์มสั้น — ปิดได้ด้วยปุ่ม ✕ (โปรแกรมอ่านหน้าจอ), แตะพื้นหลัง, escape ของ VoiceOver, back ของ Android
- **NumberPad**: แป้นตัวเลขใหญ่สำหรับน้ำหนัก/ครั้ง/แคลอรี่
- **Alert ยืนยัน**: ทุกการลบ (เซสชัน routine โปรแกรม บัญชี) และล็อกเอาต์
- **ป้ายสมาชิก** (B7) บนหน้าแรก: วันสิ้นสุดทดลอง / ใช้ได้ถึง / ปัญหาการชำระเงิน
