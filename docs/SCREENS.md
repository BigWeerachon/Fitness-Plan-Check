```

   │
   └─ /(app)  ◀── AccessGate: ต้องผ่านตั้งค่าเริ่มต้น + มีสิทธิ์ (ทดลอง/รายเดือน/ซื้อขาด/ผ่อนผัน) ไม่งั้นไป /onboarding หรือ /paywall
         (tabs) แถบแคปซูลลอย 4 แท็บ: วันนี้ /  ·  โปรแกรม /programs  ·  สถิติ /stats  ·  ตั้งค่า /settings

         ├─ /program/[id], /program/templates
         ├─ /routine/[id]
         ├─ /exercises (เลือก/ค้นหา), /exercises/new (?routineId สร้างแล้วเพิ่มเข้า routine, ?editId แก้ท่าที่สร้างเอง), /exercises/[id]
```

## 2. รายการหน้า

สถานะทั่วไปที่ทุกหน้ามี: **loading** = ตัวหมุนกลางจอ (ใช้น้อยมากเพราะ SQLite ในเครื่องอ่านแบบ synchronous), **ว่าง** = `EmptyState` ไอคอน + ข้อความ + ปุ่มทำต่อ, **error** = `ErrorState` ภาษาง่าย + ยืนยันว่าข้อมูลในเครื่องปลอดภัย, **ถูกล็อก** = ทุกหน้าใน `(app)` ถูกพาไป Paywall โดยไม่ลบข้อมูล

## 3. องค์ประกอบร่วม

- **Sheet** (แผ่นล่าง): เมนู ⋯, ตัวเลือก, ฟอร์มสั้น — ปิดได้ด้วยปุ่ม ✕ (โปรแกรมอ่านหน้าจอ), แตะพื้นหลัง, escape ของ VoiceOver, back ของ Android
- **NumberPad**: แป้นตัวเลขใหญ่สำหรับน้ำหนัก/ครั้ง/แคลอรี่
- **Alert ยืนยัน**: ทุกการลบ (เซสชัน routine โปรแกรม บัญชี) การลบท่าที่มีเซ็ตเสร็จแล้วในเซสชัน และล็อกเอาต์
- **ป้ายสมาชิก** (B7) บนหน้าแรก: วันสิ้นสุดทดลอง / ใช้ได้ถึง / ปัญหาการชำระเงิน
- **Disclaimer** (`src/components/Disclaimer.tsx`): กล่องคำเตือน "ไม่ใช่อุปกรณ์การแพทย์" (H5) + ลิงก์ "แหล่งอ้างอิง" ไป `/references` (H6, N1) — อยู่ในทุกหน้าที่แสดงผลคำนวณ: วันนี้, สถิติ, กราฟความแข็งแรง, โปรไฟล์, สรุปเซสชัน, รายละเอียดประวัติ, ตั้งค่า และหน้าแหล่งอ้างอิงเอง (ซ่อนลิงก์ `showSources={false}`) (D72)
- **MuscleIcon**: ไอคอนกล้ามเนื้อวาดเองด้วย `react-native-svg` (ร่างเส้นเดียวกัน เติมสีหลักเฉพาะบริเวณ) ใช้ในคลังท่า รายละเอียดท่า และหัวท่าในเซสชัน — เป็นของตกแต่ง ซ่อนจาก screen reader เพราะมีชื่อกล้ามเนื้อเป็นข้อความอยู่แล้ว (D71) ไอคอนที่ใช้ร่างด้านเดียวกัน (ไบเซปส์/ไตรเซปส์, แฮมสตริงส์/ควอดส์) ดูคล้ายกัน — ต้องตรวจภาพบนเครื่องจริง (OPEN_QUESTIONS Q17)
- **Stepper**: ปุ่ม −/+ ซ่อนจาก VoiceOver/TalkBack ผู้ใช้ screen reader ปรับค่าด้วยท่า swipe up/down (D74)
