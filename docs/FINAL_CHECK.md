## 6. ความเสี่ยงที่ทราบ (ยังเหลืออยู่)

1. **Apple บน Android เพิกถอนโทเค็นไม่ได้ (D40, OPEN_QUESTIONS Q12)** — iOS ขอ authorization code ใหม่เพื่อให้เซิร์ฟเวอร์เพิกถอน แต่ Android ใช้ OAuth เว็บจึงไม่มี code; ผู้ใช้ต้องถอนสิทธิ์แอปเองที่ appleid.apple.com (เขียนไว้ในหน้า Privacy) และถ้าเพิกถอนล้มเหลวระบบยังลบข้อมูลต่อและรายงานผล
2. **ราคาขั้นต่ำเงินบาทยังไม่ได้ยืนยัน (J2)** — เป้า 19/99 บาทอาจตั้งไม่ได้ (ต้องเลือกราคาที่ใกล้และต่ำสุดที่สโตร์อนุญาต) ไม่มีใครตรวจได้นอกคอนโซลของเจ้าของ ตาราง HT 58 ยังว่าง
3. **ชื่อเมนูในคอนโซล (Apple/Google/Supabase/RevenueCat) ยังไม่ได้ยืนยัน** — คู่มือ HUMAN_TASKS เขียนจากความรู้ ณ เวลาเขียน ชื่ออาจเปลี่ยน (หัวเอกสารให้ค้นด้วยชื่อในวงเล็บ)
4. **ไอคอนกล้ามเนื้อยังไม่ได้ดูบนเครื่องจริง (D71, OPEN_QUESTIONS Q17)** — วาดเองด้วย SVG บนร่างเส้นเดียวกัน บางคู่คล้ายกัน
5. **ภาพหน้าจอตรวจจากพรีวิวเว็บเท่านั้น (D43)** — ฟอนต์/เงา/สัดส่วนอาจต่างจาก iOS/Android และภาพที่มีเก่ากว่าโค้ด (G-02) ยังไม่เคยรันบนเครื่องจริงหรือ simulator
6. **ไม่มี push notification และไม่มีตัวนับเวลาทดลองในแอปโดยตั้งใจ** (D17, B2) — ตัวจับเวลาพักเตือนด้วย haptic เฉพาะตอนแอปเปิดอยู่; ผู้ใช้จะรู้ว่าทดลองใกล้หมดจากป้ายวันที่ในแอปและการแจ้งเตือนของสโตร์เอง
7. **ข้อสันนิษฐานเรื่องพฤติกรรม RevenueCat/สโตร์ที่ยังไม่ยืนยันบนเครื่อง** — D49 (ข้อมูล SDK เก่ากว่า 5 นาที = จากแคชตอนออฟไลน์), D64 (ซื้อขาดที่คืนเงินแล้วหายจากรายการธุรกรรม), D65 (พฤติกรรม restore ตั้งใน RevenueCat), Android ถือว่ามีสิทธิ์ทดลองถ้า Play ส่ง free-phase offer มา (พึ่งการตั้ง "New customer acquisition", B6)
8. **ฝั่งเซิร์ฟเวอร์ทดสอบด้วยตัวแทน auth (D41)** — `supabase:verify` ใช้ Postgres จริงแต่ stub ของ `auth.uid()`/roles ต้องทดสอบซ้ำหลัง deploy (HT 70, P-15/P-16)
9. **เอกสารกฎหมายยังเป็นเทมเพลต** — ไม่ได้ผ่านทนาย มี placeholder 5 ตัว (`developer`, `contact`, `address`, `effective`, `law`); เทสต์ guard `RELEASE=1` จึงถูกข้ามอยู่ 1 ข้อจนกว่าเจ้าของกรอก
10. **สิ่งที่หมดอายุเอง** — Apple OAuth client secret (JWT ≤ 6 เดือน) ถ้าลืม Sign in with Apple บน Android ใช้ไม่ได้ (HT 82); ใบอนุญาต Apple Developer รายปี (HT 83)
11. **ยังไม่เคย build ด้วย EAS และยังไม่เคยรันบนเครื่องจริง (D21)** — `expo export` + `expo prebuild` ผ่านเท่านั้น ปัญหา native ที่เกิดตอน build/รันจริง (เช่น การกำหนดค่าปลั๊กอิน Google Sign-In ที่ใช้ placeholder `com.googleusercontent.apps.placeholder`) จะเห็นครั้งแรกตอนทำ HT 39
12. **Supabase Auth อาจเก็บชื่อและรูปโปรไฟล์จาก Google (และชื่อจาก Apple บน Android) เอง** แม้แอปไม่ขอและไม่ใช้ — ยังไม่ได้ตรวจในระบบจริง (ดู `store-metadata/privacy-labels.md` ข้อ 2.1, OPEN_QUESTIONS Q16) ถ้าพบต้องตัดทิ้งฝั่งเซิร์ฟเวอร์หรือประกาศ "Name" ในป้ายความเป็นส่วนตัว (กระทบ B13/N1.4)
